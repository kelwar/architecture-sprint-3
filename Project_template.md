### 1. Описание функциональности монолитного приложения

**Управление отоплением:**

- Пользователи могут удалённо включать/выключать отопление в своих домах.
- Система поддерживает установку целевой температуры отопления.
- Пользователям доступно множественное изменение параметров отопления.

**Мониторинг температуры:**

- Пользователи могут просматривать текущую температуру в своих домах через веб-интерфейс.
- Система получает данные о температуре с датчиков, установленных в домах.
- Система не поддерживает самостоятельное добавление датчиков к системе пользователем.

### 2. Архитектура монолитного приложения

- Язык программирования: Java
- База данных: PostgreSQL
- Архитектура: Монолитная, все компоненты системы (обработка запросов, бизнес-логика, работа с данными) находятся в рамках одного приложения.
- Взаимодействие: Синхронное, запросы обрабатываются последовательно.
- Масштабируемость: Ограничена, так как монолит сложно масштабировать по частям.
- Развёртывание: Требует остановки всего приложения.

### **4. Проблемы монолитного решения**

- Ограниченный функционал. Поддерживается только один вид устройств и датчиков - не соответствует заявленной цели.
- Проблемы масштабирования. Система не поддерживает самостоятельную установку устройств - компания не успеет в заданные сроки подключить оставшуюся половину домов, а также установить дополнительные датчики и реле.
- Проблемы масштабирования. Система не имеет разветвленной иерархической структуры серверов и устройств и не поддерживает асинхронные вызовы - сервера компании и сетевая инфраструктура могут не справиться с резким увеличением количества активных пользователей.
